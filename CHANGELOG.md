# Changelog

All notable changes to this plugin are documented here. This project follows [Semantic Versioning](https://semver.org/).

## [1.1.0] - 2026-11-17

### Added

- Gemini plugin manifest at `.gemini-plugin/plugin.json`.
- Root `.mcp.json` with the remote Linear MCP server configuration.
- `linear-workspace` skill with general rules for working in Linear through the MCP server.
- `CHANGELOG.md` and `LICENSE`.

## [1.0.0]

### Added

- Cursor plugin manifest at `.cursor-plugin/plugin.json`.
- Agent Plugins manifest (`plugin.json`) and MCP configuration (`mcp.json`).
- Connection to the remote Linear MCP server at `https://mcp.linear.app/mcp`.
